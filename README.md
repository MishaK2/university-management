# University Management System — TypeScript & Enum

## Мета роботи
Отримати практичні навички роботи з TypeScript та Enum через створення системи управління навчальним процесом університету.

## Структура проєкту

src/
└── university.ts — вся логіка в одному файлі
tsconfig.json
package.json
README.md


## Реалізовано:
- Enum: StudentStatus, CourseType, Semester, GradeValue, Faculty  
- Інтерфейси: Student, Course, GradeRecord  
- Клас UniversityManagementSystem  
- Реєстрація студента  
- Реєстрація на курс з перевірками  
- Виставлення оцінки  
- Зміна статусу студента з валідацією  
- Середній бал  
- Список відмінників  
- Повна типізація та коментарі  

## 👨‍💻 Технології
- TypeScript  
- Node.js
